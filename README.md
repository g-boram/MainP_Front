###이름: hicar 중고차 거래 사이트


###목적: 
중고차 거래를 지원하는 플랫폼으로 판매 차량검색, 내차 견적내기, 정비에대한 거래를 원스톱으로 진행가능하며 신뢰도 있는 중고차 거래 사이트를 만들기 위해 제작하였습니다.

###사용기술:
react, Axios, redux, emotion, 카카오 지도, 차트,  토스sdk, openAI...

###데이터베이스:
MySQL

###주요기능

1. **사용자 인증 및 권한 관리**
   - 이메일 및 소셜 지원
   - 일반 사용자와 권한 (관리자, 판매사원, 정비소) 역할 구분
    
2. **차량 검색 및 필터링**
   - 차량 제조사, 모델, 연식, 주행거리 등 다양한 필터 제공
   - 이벤트 상품 정렬기능

3. **차량 상세 정보 페이지**
   - 차량 사진, 상세 스펙(제조사, 연식, 주행 거리 등), 차량 설명.
   - 판매자 정보와 문의 버튼 제공.
   - 

4. **AI 채팅 시스템**
   - 웹사이트에 제공된 open ai 챗봇과 채팅 가능

5. **온라인 결제 시스템**
   - 토스 sdk 를 이용한 온라인 결제 가능
    
6. **관리자 대시보드**
    - 권한별 지정된 관리기능
    - ADMIN
      : 회원관리 (등록, 수정, 삭제, 권한 변경등 )
      : SELLER, REPAIR 전체 기능 가능 
    - SELLER
      : 온란인 견적서 현황 차트 보기 (월별건수, 지역별, 색상별)
      : 차량 이벤트 등록 및 상품 게시글 관리 기능.
      : 온라인 견적 신청서 상태(처리 중, 점검중, 판매 완료 등) 변경.
      : 차량 게시글 조회
    - REPAIR
      : 차량 점겅 작성 및 수정,삭제
      : 차량 게시글 조회
